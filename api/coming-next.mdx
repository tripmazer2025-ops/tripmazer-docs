These jobs are planned. They'll use the same keys, credit, job object and webhooks as Reel to Trip, so an integration built today covers them as they arrive. Plans can change; this page shows what's planned now.

| Job | What it will do |
| --- | --- |
| **Watch a trip** | Send a booking email, PDF or flight numbers; get delay, gate, cancellation and schedule-change events until landing, with options when a flight breaks |
| **Call a business** | Mazer phones a hotel, restaurant or airline in the local language with your questions and returns the answers and transcript |
| **Web errand** | A task on a real website, finished with sources and screenshots |
| **Route** | The fastest, cheapest and overnight ways across flights, trains and buses in India |
| **Price watch** | A webhook the moment a fare falls below your line |
| **Book** | A hosted checkout for a flight; the ticket and a watched trip follow |
| **Booking documents** | A branded e-ticket or voucher PDF and a Google Wallet pass from any booking |
| **Check on me** | A safety timer that alerts a traveller's contacts if they don't answer |
| **Card perks** | Which airport lounges an Indian card opens, from the bank's own terms |
| **Audio guide** | Narrated chapters for a trip or a place, as a podcast feed |
| **Trip reel** | Photos and clips in, a short music video with captions out |

## MCP

Every job will also be an MCP tool, so an AI agent in Claude, ChatGPT, Cursor or any MCP client can start a job and wait for its result.
