The Mazer MCP server offers the live jobs as tools. It speaks MCP over streamable HTTP and uses your API key, so test and live mode, credit, limits and the request log work exactly as they do over REST.

**Server URL:** `https://wiunqzjefneakwtlbgpp.supabase.co/functions/v1/mazer-mcp`
**Auth:** `Authorization: Bearer tm_test_…` (or a live key)

## Tools

| Tool | What it does |
| --- | --- |
| `reel_to_trip` | Every place in a travel video, checked on the map |
| `watch_trip` | Watch a traveller's flights until they land; flights or itinerary text in |
| `trip_status` | A watched trip now: flights, times, gates and what happened |
| `find_options` | Other ways there for a trip's flight |
| `route_india` | Fastest, cheapest and overnight ways between Indian cities |
| `weather_plan_b` | A day's stops checked against the forecast, with indoor swaps |
| `airport_brief` | The lounges a traveller's cards open at an airport |
| `booking_documents` | A branded e-ticket or voucher PDF and Wallet passes |
| `call_business` | A real call to a business with your questions; the answers and transcript |
| `trip_reel` | A finished travel video with music, from photos and clips |
| `trip_story` | A travel story, ready to post, from an itinerary, photos and notes |
| `audio_guide` | Narrated chapters for a place or a trip, as a podcast feed and MP3 links |
| `check_on_me` | A traveller's safety timer, with opt-in links for them and their contacts |
| `checkin_status` | A check-in now: its status and who has linked a chat |
| `job_status` | A job's status and result, for a job that was still running |

More jobs join as they go live.

```bash

  --header "Authorization: Bearer $TRIPMAZER_KEY"
```
  </Tab>

Start with a test key: `watch_trip` then opens a simulated trip, and nothing is charged.
