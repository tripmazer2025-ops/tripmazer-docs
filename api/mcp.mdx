The Mazer MCP server offers the live jobs as tools, so an AI app can start them and read what comes back.

**Server URL:** `https://mcp.tripmazer.com/mcp`

There are two ways in:

| | How | Use it for |
| --- | --- | --- |
| **Sign in** | The app opens TripMazer, you choose the account, test or live, and the most it can spend a day | Claude, Claude Code and other apps that sign in |
| **API key** | `Authorization: Bearer tm_test_…` (or a live key) | Your own agents and servers |

Either way, test and live mode, credit, limits and the request log work exactly as they do over REST. The server speaks MCP over streamable HTTP and OAuth 2.1 with PKCE.

## Tools

| Tool | What it does |
| --- | --- |
| `reel_to_trip` | Every place in a travel video, checked on the map |
| `watch_trip` | Watch a traveller's flights until they land; flights or itinerary text in |
| `trip_status` | A watched trip now: flights, times, gates and what happened |
| `find_options` | Other ways there for a trip's flight |
| `route_india` | Fastest, cheapest and overnight ways between Indian cities |
| `weather_plan_b` | A day's stops checked against the forecast, with indoor swaps |
| `airport_brief` | The lounges a traveller's cards open at an airport |
| `booking_documents` | A branded e-ticket or voucher PDF and Wallet passes |
| `call_business` | A real call to a business with your questions; the answers and transcript |
| `trip_reel` | A finished travel video with music, from photos and clips |
| `trip_story` | A travel story, ready to post, from an itinerary, photos and notes |
| `audio_guide` | Narrated chapters for a place or a trip, as a podcast feed and MP3 links |
| `check_on_me` | A traveller's safety timer, with opt-in links for them and their contacts |
| `checkin_status` | A check-in now: its status and who has linked a chat |
| `job_status` | A job's status and result, for a job that was still running |

More jobs join as they go live.

## Connect

<Tabs>
  <Tab title="Claude">
    In Claude, open **Customize**, then **Connectors**, add a custom connector and paste `https://mcp.tripmazer.com/mcp`. Sign in to TripMazer when it asks.
  </Tab>
  <Tab title="Claude Code">
```bash
claude mcp add --transport http mazer https://mcp.tripmazer.com/mcp
```
    Then run `/mcp` and choose **Authenticate**. To use a key instead, add `--header "Authorization: Bearer $TRIPMAZER_KEY"`.
  </Tab>
  <Tab title="Cursor">
```json
{ "mcpServers": { "mazer": { "url": "https://mcp.tripmazer.com/mcp" } } }
```
    Sign in when Cursor asks. To use a key instead, add `"headers": { "Authorization": "Bearer tm_test_…" }`.
  </Tab>
</Tabs>

## What you agree to

The page you sign in on says which app is asking and the address it answers to. Connect only an address you know.

- **It can** run Mazer jobs on the account you choose, and see that account's jobs, trips and check-ins.
- **It can't** see your keys, add credit or change settings.
- **Test** returns samples and never charges. **Live** runs real jobs, up to the daily limit you set.
- Only an owner or admin of the account can connect an app.

Disconnect an app any time under **API keys**, **Connected apps** in the [console](https://tripmazer.com/developers/console/keys). It stops at once.
