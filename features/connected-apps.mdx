## Outlook and other email

On **Pro** and **Elite**, Mazer can read more than Gmail. Connect them in **Settings → Integrations**:

- **Outlook** has its own connector. In chat it does everything Gmail does: search, read, draft, send, reply, archive and import bookings. Sending and changes are approved first.
- **Other email** covers iCloud, Yahoo, Zoho and any other mailbox that supports IMAP. Tap **Connect other email** and enter your address, your provider's IMAP server and an **app password** you make with your email provider. Mazer can search and read it, import bookings from it, and save drafts into its Drafts folder. It never sends from it.

Both are scanned for bookings like Gmail, and for bank alerts and refunds if you've turned that on.

<Warning>Only type an app password into that form. Mazer never asks for one in chat, so never paste one there.</Warning>

<Note>Calendar, Gmail and Splitwise sync are part of Pro and Elite. X runs on X's pay-per-use API, so Mazer only uses it when you name X.</Note>

## Approvals

Nothing is sent, added, changed or removed in a connected app without your approval:

- **Web**: a one-tap approval, or "send it" for a saved draft
- **WhatsApp and Telegram**: a **Confirm** button
- **Mazer Live**: Mazer reads it back and waits for a clear "yes"

Publishing and deleting posts always go through their own step-by-step confirmation, and are never done by a schedule or routine on its own.

## Bring your own MCP server

If you use a tool that has an MCP server, such as Linear, you can connect it yourself:

<Steps>
  <Step title="Open MCP Servers">
    Go to **Settings → Integrations → MCP Servers** and choose **Add server**.
  </Step>
  <Step title="Enter the server">
    Give it a name and its URL (for example `https://mcp.example.com/mcp`). Add a bearer token only if the server needs one.
  </Step>
  <Step title="Authorise">
    If the server uses sign-in, you're sent to it to approve access.
  </Step>
</Steps>

Mazer can then read from the server's tools once you approve them. Anything that changes data asks first.

<Warning>MCP servers aren't built or reviewed by TripMazer. Connect only servers you trust, and remember they can do only what their own tools allow.</Warning>

## When something isn't working

Ask Mazer **"is my Gmail connected?"** or **"why did that fail?"**. It checks which accounts are live or need reconnecting, and tells you the real reason something failed.

To disconnect an app, go to **Settings → Integrations** and choose **Disconnect**.
